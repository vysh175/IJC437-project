# IJC437 – Rail Passenger Demand Volatility Analysis (R)

This repository contains my coursework project for the IJC437 module.  
The analysis cleans passenger journey datasets, visualises demand patterns, measures volatility, and clusters operators based on volatility.

## Files
- `index.md` – Profile page (GitHub Pages)
- `ijc437.md` – Project page (GitHub Pages)
- `ijc437_analysis.R` – Main R script (analysis)

## Requirements
- R (latest recommended)
- RStudio

## Packages used
Install these in R if missing:
- tidyverse
- readODS
- janitor
- cluster
- scales

## How to download and run
1. Click the green **Code** button → **Download ZIP**.
2. Extract the ZIP file.
3. Open RStudio and set the working directory to the extracted folder.
4. Open the `.R` script.
5. Install missing packages using `install.packages("package_name")`.
6. Run the script from top to bottom to reproduce the analysis and outputs.
